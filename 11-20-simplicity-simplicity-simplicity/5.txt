The Simplicity Rule
===================

simplicity.png

If the options in {a,b,c,...|d,e,f,...} are all numbers, we'll say that the number x *fits* if:

- a,b,c,... are all strictly less than x
- x is strictly less than d,e,f,...

and x will be the *simplest* number that fits if none of its options do.

For example, {2⅜|5} = 3 because 3 = {2| }, and 2 does not lie between 2⅜ and 5, while 3 does. Also, {2½| } = 3, {-2½| } = 0. ({a| } is a number greater than a having no option greater than a, and { |b} is a number smaller than b having no option with this property.)
